# 爽哥面板隧道助手

**版本 V2.3 ｜ 出品：杨爽工作室**

一键建立 SSH 隧道，从本地安全访问远程服务器上的管理面板（1Panel、雷池 WAF 等）。面板端口对外保持关闭，只有隧道能通，浏览器照常开 `127.0.0.1` 就能进后台。

---

## 一、为什么需要它

服务器是动态公网地址，没法做固定 IP 白名单；而把 1Panel（40001）、雷池 WAF 面板（16002）这类管理后台直接暴露到公网，等于把大门敞开，天天被扫。

本工具的做法是 **SSH 本地端口转发**：把远程面板端口映射到本机 `127.0.0.1` 上，数据全程走加密的 SSH 通道。对外只开一个 SSH 端口，面板端口可以从防火墙彻底关掉。

## 三、准备与运行

### 1. 三件东西放同一目录

```
爽哥面板隧道助手.exe
server_key        ← SSH 私钥（用密钥认证时需要）
config.json       ← 配置，首次手动创建或用程序内「保存配置」生成
```

### 2. 双击运行

免安装、无第三方运行时依赖、无注册表写入。窗口是暗色主题，主操作按钮特意做大（16pt），远程桌面或投屏操作时也点得准。

> 图标与赞助二维码资源已内嵌进 exe，转发给朋友时**不需要带 `assets` 目录**。

### 3. 首次配置

如果同目录没有 `config.json`，界面字段会留空并给出提示。手填各项后点「保存配置」即可生成，或者点「重新加载」读入已有配置。

## 五、标准操作流程

1. 填好服务器 IP、SSH 端口、用户名
2. 选认证方式
   - **密钥认证**：填私钥路径，推荐只写裸文件名 `server_key`（程序按 exe 同目录解析，换电脑也不失效）
   - **密码认证**：输入密码；想下次免输入就点「保存配置」，密码会加密落盘
3. 下拉选择目标面板 → 本地 / 远程端口自动填好
4. 点「**启动隧道**」→ 状态变绿「隧道已连接」即成功
5. 点「**打开面板**」→ 浏览器打开对应后台
6. 用完点「**停止隧道**」；直接关窗也会先终止 ssh、清空密码、删除临时凭据文件，不留残留进程

## 六、配置文件说明

所有参数都来自同目录的 `config.json`，程序里没有写死任何连接信息：

```json
{
    "server": "你的服务器IP",
    "ssh_port": "22022",
    "user": "root",
    "key_path": "server_key",
    "auth_method": "key",
    "password_enc": "保存密码后自动写入的 DPAPI 密文，可留空",
    "panels": [
        { "name": "1Panel 面板", "local_port": "40001", "remote_port": "40001" },
        { "name": "雷池面板",   "local_port": "16002",  "remote_port": "16002"  }
    ],
    "current": "1Panel 面板"
}
```

| 字段 | 含义 |
| --- | --- |
| `server` / `ssh_port` / `user` | SSH 连接目标 |
| `key_path` | 私钥路径，支持裸文件名（按 exe 同目录解析）或绝对路径 |
| `auth_method` | `key` 密钥认证 / `password` 密码认证，缺省按 `key` |
| `password_enc` | 密码的 DPAPI 密文，绑定当前 Windows 用户；**程序永远不会把明文密码写进这个文件** |
| `panels` | 面板数组，每项含名称与本地 / 远程端口 |
| `current` | 当前选中的面板名（下拉框只显示纯名称，不带端口后缀） |

三条约定：

- **空即空**：空值不会被回填成默认值，你填什么就是什么
- **加面板**：在 `panels` 里加一项，点「重新加载」即可，不用改程序、不用重启
- **本地 ≠ 远程也可以**：比如远程 16002 想映射到本地 26002，把 `local_port` 改掉即可

> 配置写盘采用「临时文件 → fsync → 原子替换」，中途断电或强杀进程只会留下临时文件，原配置永远是完整可解析的 JSON，不会变空文件。

## 七、密码与密钥是怎么保护的

| 项 | 做法 |
| --- | --- |
| 密码明文 | 只在内存与环境变量中流转，**不落盘、不进命令行参数、不打日志、不写临时文件** |
| 密码递交 | 走 `SSH_ASKPASS` + 一次性临时脚本，隧道停止或程序退出即删除 |
| 密码保存 | 勾选保存时用 Windows DPAPI 加密为 `password_enc`，**只有当前 Windows 用户能解密** |
| 换机 / 换用户 | 密文解不开时自动删除失效密文并给非阻塞提示，重新输一次密码即可 |
| 私钥权限 | 启动前自动 `icacls` 收紧为仅当前用户可读，绕开 Windows 下 ssh 的 `Bad permissions` |
| 私钥路径 | 推荐裸文件名，避免把本机绝对路径写进配置（换机即失效，还会暴露目录结构） |

## 八、常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 一启动就「隧道出错」并提示端口占用 | 上次异常退出残留的 `ssh.exe` 还占着本地端口。任务管理器结束它，或直接用提示的**替代端口** |
| 提示私钥权限错误 | 私钥 ACL 过宽被 ssh 拒绝。程序会自动修复；仍失败时手动去掉继承权限、只授予当前用户 |
| 密码认证一直失败 | 密码错，或服务器 sshd 禁了密码登录。核对密码并确认 `PasswordAuthentication` 为 yes |
| 换电脑后密码框为空还有提示 | DPAPI 密文绑定原 Windows 用户，无法解密属正常。重新输入密码并保存，失效密文会被自动清掉 |
| 点按钮没反应 | 上一次动作还没结束（忙碌态），按钮变灰即在处理，等状态行提示消失即可 |
| 状态一直停在「启动中」 | 看日志区 ssh 原文与下面的中文提示两行；常见是主机不通、认证失败、端口占用 |
| 日志区不自动滚了 | 你手动上滚过，跟随被暂停。滚回底部或点「滚到底」恢复 |
| 「打开面板」是灰的 | 只在「隧道已连接」状态可用，先启动隧道 |
| 换服务器怎么改 | 改 `config.json` 后点「重新加载」，无需重启程序 |

## 十一、已知限制

1. 一台程序同时只维持**一条**隧道（切面板需先停再启）
2. 依赖系统自带的 `ssh.exe`（Windows 10/11 默认具备），老系统需自行安装 OpenSSH 客户端
3. 服务器端口若未放行 SSH，或账号被限制来源 IP，隧道无法建立
4. 密码认证能否使用取决于服务器 `sshd_config` 是否允许密码登录
5. 界面尺寸固定，不支持自定义皮肤 / 主题切换
